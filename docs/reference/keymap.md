# Keymap

Generated by `node scripts/gen-keymap-docs.mjs` from `desktop/src/shell/keymapModel.mjs` — do not edit by hand.

`Mod` is ⌘ on macOS and Ctrl elsewhere. `keymap.preset` (`default` · `vscode` · `vim`) and
`keymap.overrides` (command id → chord, `""` to unbind) are Machine-scope settings; a chord held by
two commands in one scope is refused, and the later binding is dropped with a warning. The narrowest
live scope wins when two hold one chord: `document`, `editor`, `terminal`, `files` and `browser` over `tabs` over
`workbench` and `designer` — which are never live together — over `global`.
