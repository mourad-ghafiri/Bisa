# bisa-adapters

One adapter per harness: the private vocabulary of a program — its argv, its wire format, its
notion of a session — translated into the shared one `bisa-harness` defines. This is the only
place a harness's prose is read, and it is read exactly once: a line that means *this model is
unavailable* becomes `ModelUnavailable` here, and nothing above the boundary sees the wording.

the answer is the whole option list again, and the effort is fitted to the levels *it* offers. Already on the model, or no such option: nothing is sent. Offered among models that do not include it, or refused when set: the session ends `ModelUnavailable` before any prompt, so the launch walks the plan to its next model and no session is recorded on a model it is not running ([session config options](https://agentclientprotocol.com/protocol/session-config-options), read 2026-09-30). **The draft before config options** is read the same way (`model_step` takes the whole answer): an agent that answers `session/new` or `session/load` with `models` — `availableModels`, each a `modelId` and a `name`, and `currentModelId` — and offers no `model` option is set with `session/set_model` (`ModelStep::SetModel`, the same request id, answered empty), on it already is told nothing, and listing others ends `ModelUnavailable`; an agent that advertised `models` yet answers the set *method not found* (`-32601`) ends `Failed` in its own words rather than walking every model — Gemini CLI speaks this draft (its `packages/cli/src/acp/`, read 2026-10-05; [the protocol's announcement](https://agentclientprotocol.com/announcements/session-config-options-stabilized) that the method never stabilised). **Once before always**: a permission is answered with the `allow_once` option, else the first `allow*` (`reject_once`, else the first `reject*`, for a deny), whatever order the agent lists them — Gemini CLI lists *Allow for this session* first, and the guard's one allow must never become a standing grant it is not asked about again (`permission_outcome`). A revival is asked only of an agent whose `initialize` answer says `agentCapabilities.loadSession` (*Clients MUST NOT attempt to call `session/load`* otherwise — [session setup](https://agentclientprotocol.com/protocol/session-setup)); an agent that leaves with status 0 before its session exists has failed to start (`clean_exit`), never completed a run. **A message the queue cannot take ends the session in words** (`queued`): the outbound queue is bounded, and a `session/new`, a model or effort option or the first prompt it cannot hold is a step lost — nothing would ever answer it — so the session ends `Failed` naming which message, never left *starting* or holding a first prompt nobody will run until a clock elsewhere notices (`a_protocol_message_the_queue_cannot_take_ends_the_session_in_words`) |

### Effort

One vocabulary above the adapters, each harness's own control below them
([06 § Effort](../06-agents-and-teams.md#effort)). Every adapter with the control declares
`HarnessCaps::EFFORT`, answers `efforts(model)` from a table read from the harness's own
documentation (2026-09-29), holds the level it is handed to that table once more before it sends
it — a level a harness would refuse never reaches it — and mints a `ResumeToken` with the model and
the effort the session ran with (`util::Shared::resume_token`), which `attach` hands back.

| Adapter | The level is passed as | `efforts(model)` |
|---|---|---|
| `claude_code.rs` | `--effort <level>` after `--model`, at launch and at `attach` | `efforts_for`: the `[1m]` suffix set aside, then none for Haiku, five levels for Fable, Opus 4.7 and later, Sonnet 5 and later and the aliases, four (no `xhigh`) for everything else and for no model |
| `codex.rs` | `-c model_reasoning_effort="<level>"` after `-m`, every turn; the prompt stays last | `EFFORTS`: `low`, `medium`, `high` |
| `opencode.rs` | `--variant <level>` after `--model`, every turn | `efforts_for`: by the id's provider prefix — `anthropic/`, `openai/`, `google/`; none otherwise |
| `pi_rpc.rs` | `--thinking <level>`, at launch and at `attach` | all six |
| `omp.rs` | `pi_wire::set_thinking_level`, written after `get_state` and before the first prompt | all six |
| `acp.rs` | `session/set_config_option` (request `ID_EFFORT`) on the `thought_level` option the session offers **once it is on its model** — the list the model's own answer carries when the model was set, else the `session/new` (or `session/load`) result's — its values matched to levels whatever their case and separators, the level fitted among them; nothing when none is offered | all six may be asked for |
| `copilot.rs` | as `acp.rs` — the session's option; no `--effort` word | `efforts_for`: `low` … `max` for a `claude-*` model (*`max` is the highest-depth tier for Anthropic models*), `low` … `xhigh` for any other and for none |
| `grok.rs` | as `acp.rs` — the session's `reasoning_effort` option | `minimal` … `xhigh`, for every model |
| `gemini.rs` | nothing — its session offers no `thought_level` option and the CLI documents no control for how hard a model works | none; no `EFFORT` cap, so a step's pin on it is an `UnsupportedEffort` |
| `a2a.rs`, the presets, a custom harness | nothing | none, and no flag |

Claude Code's curated model list leads with the two the platform ships on
(`RECOMMENDED_MODELS`: `claude-opus-5-5[1m]`, `claude-sonnet-5-5[1m]` — its `recommended_plan`; the
second is its `recommended_judge`), each id listed with and without `[1m]` because a step's model
pin is held to the list by equality. Copilot CLI's list is its reference's table and leads with its
documented default (`copilot::DEFAULT_MODEL`, its plan and its judge); Grok Build's is what its own
`grok models` prints, and it recommends none. Gemini CLI's is the table its own page gives
(`gemini::MODELS`, `auto` first, the CLI's default), and it recommends none either — a preview id
written as a recommendation could retire. A harness opened in a terminal is given no model and
no effort.

## Tests

`tests/it/adapters.rs`, `tests/it/a2a.rs`; unit tests beside each wire — `claude_code::tests` holds the allowlist to `TodoWrite` and the `Platform` mounts alone, an installed server mounted but never pre-allowed. `acp`'s hold a tool call to its id (`a_tool_call_is_known_by_its_id_whatever_a_later_message_leaves_out`, `a_tool_keeps_the_name_it_started_under_and_is_forgotten_once_it_ends`, `a_turns_end_forgets_the_calls_it_left_open_and_the_memory_has_a_bound`, `a_kind_is_the_tier_of_what_it_can_change`), a loaded session to the id it was asked for, and the first prompt until the session exists; the hook translators' hold each harness's payloads to the engine's events. `copilot`'s, `grok`'s and `gemini`'s hold each harness's command, levels, models and terminal form; in `tests/it/adapters.rs` a stub agent that chooses its model is driven through each adapter — one on the draft, answering `models` and `session/set_model`, through Gemini's. From end to end an ACP agent is the scripted one of the journeys (`crates/bisa-cli/tests/scripted_agent.rs`), which tells every call as the protocol does — placed as `goose` for the generic target, and as `copilot`, `grok` and `gemini` in `e2e/copilot_grok_and_gemini.rs`, Gemini's script speaking the draft.
