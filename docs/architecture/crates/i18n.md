# bisa-i18n

The catalog and its rendering ([17 — Internationalisation](../17-internationalisation.md)): every
message the platform says to a person, in Fluent under `locales/<lang>/`, one locale negotiated
once, and a `Text` — the sentence as data, `bisa_core::text::Text` — rendered into one language at
the edge that talks to the person: the node's error body, the CLI, the docs generators. One Bisa
dependency, `bisa-core`, for `Text`; the Fluent crates do no I/O — the catalog files are compiled in
(`include_str!`), so a node or a CLI carries its languages and reads nothing at run time.

---

## Where things live

| Module | Owns |
|---|---|
| `lib.rs` | the crate's door: `render(locale, text)`, `attribute(locale, id, name, text)`, `english(text)` over the global catalog; `content_id(kind, slug)` and `content(locale, id, attribute, fallback)` — the catalog's display fields, the file's text when no message ships |
| `locale.rs` | `Locale`: `parse` (a POSIX tag without its encoding; `C` is nobody's language), `from_env` (`LC_ALL` · `LC_MESSAGES` · `LANG`), `from_accept_language` (tags by quality), `negotiate` against `AVAILABLE` with English as the default; `AVAILABLE`, `DEFAULT` |
| `catalog.rs` | `Namespace` — the six files the crates own (`settings`, `errors`, `problems`, `engine`, `cli`, `catalog` for the content seam), each compiled in per shipped language; `Catalog` — one concurrent `FluentBundle` per language, isolation off, `render` (a missing message is its id, said once in the log), `attribute`, `has`, `shipped()`, `from_sources()` for a test |
| `process.rs` | one language for one process — the CLI's, set once from `--lang` or the environment (`set`, `current`), so any line a pure helper composes says a `Text` in it (`say`) without an `Out` in reach; the node never uses it, rendering per request instead |
| `ratchet.rs` | the migration's guard: `prose_literals(source)` — the string literals of a Rust source that read as a sentence, minus a log line, a panic, an `expect`, an attribute, a `RouteDoc`, a comment, a test item (`#[cfg(test)]` exempts the item it stands on — a module with its body, a function, a module declared by name — and nothing below it; a file that begins `#![cfg(test)]` is a fixture whole), a line or statement under a marker (`// for the agent`, `// for the machine`, `// for the log`, `// content, never translated`), and every file in `NOT_FOR_A_PERSON` (`a2a.rs`, `route_docs.rs`, `bin/`) — `baseline(root, SCOPES)` per file, `listing(root, SCOPES)` per line, `compare(was, now)` |
| `bin/i18n-ratchet.rs` | `--write` records the baseline (`tests/ratchet.baseline.json`), `--list` prints every bare sentence as `path:line: literal` (`--list --scope <dir>`, repeatable, reads a folder outside the ratchet's own — a look at a crate before it is brought under it); without either, the report of what rose and what fell |

## Entry points

`bisa_i18n::render(&locale, &text)` — the sentence; `bisa_i18n::english(&text)` — what a docs
generator writes and a test compares; `Locale::from_accept_language(header)` in the node's
middleware, `Locale::from_env()` in the CLI.

## Invariants held here

| Rule | Test |
|---|---|
| every `.ftl` under `locales/` parses; a shipped language has every namespace; the desktop's `AVAILABLE` equals this crate's | `tests/it/catalog.rs` |
| every `text!` in the crates names a message with exactly the message's arguments; every crate-owned message is said, or is a setting's derived id (`setting-<key>`), or a content seam id (`catalog-…`); a content message names a shipped entry and its kind's display fields | `tests/it/catalog.rs` |
| arguments ride through, a plural is the message's choice, an attribute is read, no isolation marks, a miss renders as the id, a language not shipped falls back to English | `tests/it/render.rs` |
| the node's and the CLI's sources carry exactly the baseline's bare sentences | `tests/it/ratchet.rs` |
| a POSIX tag is read without its encoding, negotiation falls back to English, an `Accept-Language` is ordered by quality | `src/locale.rs` unit tests |
| the scanner sees a sentence and not a log line, a panic, an attribute, a `RouteDoc`, a comment, a test module, a raw string's quotes; a `#[cfg(test)]` item is exempt and what stands below it is still read (`a_test_item_is_exempt_and_what_stands_below_it_is_still_read` — read as the end of the file, a `#[cfg(test)] mod verbs;` near the top of `main.rs` hid every sentence below it) | `src/ratchet.rs` unit tests |

## Errors

None to a caller: a message the catalog lacks renders as its id and is logged once
(`bisa_i18n` target, `warn`); a message that formats with faults renders what it can and is logged
at `debug`. A catalog that does not parse fails the guard, and the global catalog's first use panics
with the parse errors — a build fault, never a run-time surprise.

## Extension points

A **language**: a folder under `locales/`, its tag in `AVAILABLE` and in `Namespace::source`'s
match, the same tag in the desktop ([recipe 25](../../contributing/recipes.md#25-add-a-locale)).
A **message**: written in the owning `.ftl`, said with `text!` — the guard holds the two together
([recipe 26](../../contributing/recipes.md#26-say-something-to-a-person)).

## Tests

`scripts/test crate i18n` — the guards over the catalog and the sources (`tests/it/catalog.rs`),
rendering (`tests/it/render.rs`), the ratchet (`tests/it/ratchet.rs`), the locale and scanner unit
tests. Read-only: every test walks `locales/` and `crates/*/src` and writes nothing; the baseline is
written by the binary alone, on request (`just i18n-baseline`).
