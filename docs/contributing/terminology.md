# Terminology

The vocabulary is part of the design, and it is **lint-enforced**.
One word per concept,
the same word in the code, on the wire, in the CLI, in the UI and in the docs.

| Say | Never |
|---|---|
| goal | the old domain noun |
| channel | room-like synonyms; the old noun for a channel |
| direct channel | a "DM" as a kind — `dm` survives only as a route name in the desktop and the CLI verb |
| General Agent, `general-agent` · Workflow Agent, `workflow-agent` | any older id |
| **Decision-Making Agent**, `decision-making-agent` — the third core agent, the one that judges: a decision point asks it a typed question and it answers with a **judgement** ([15](../architecture/15-decision-making-agent.md)); `DecisionMakingAgent`, `decision_making_agent` on the wire; **decision making** is the switch an agent or a workflow carries (`decision_making`) and the Settings panel's name, under the group *Decision Settings* | its older name, in any spelling — the hyphen, the underscore, the hump or two words; *model* for it; *a decision* for what it answers — a **decision** is a person's signed approval |
| GEP | the older protocol name |
| **addon** — a folder of HTML that floats over the desktop as a window, installed and granted ([18](../architecture/18-addons.md)); its **manifest**, its **record**, its **bundle**, a **grant** | *plugin*, *extension*, *widget* (the app's own footer read-outs and cards are not addons) |
| **drawing** — a picture on the **canvas**, a record of the workspace (kind 33401) attached to an `OwnerScope` like a note ([19](../architecture/19-drawings.md)); its **scene** is Excalidraw's elements, vector only; a **template** is a skeleton *New* starts from, shown in the *New drawing* dialog as a tile with a **preview** and a **blurb**; a **shape library** is the platform's items in the canvas's sidebar; a **request** is a drawing tool call parked for the desktop | *diagram* for the record (a Mermaid diagram is the viewer's), *whiteboard*, *sketch*, *image* for a drawing |
| `draft` · `running` · `waiting` · `done` · `failed` · `closed` — a goal's **status**, a projection | a lifecycle **state**; any of the retired state names |
| **archive** / **unarchive** — put a goal, a workflow or a project away, or take it back out: a mark (`archived`), never a status; **retire** — archive or delete a goal or a workflow on a plan that names what becomes of the projects born of it (`retire.rs`, the retirement dialog); what a retirement ends is said in the close's words — a harness is **terminated**, a shell **closed**, an engine session **aborted**, the run **cancelled** | *archived* as a goal status; *remove* for a goal; *stopped* or *killed* for what a retirement ends |
| `approval` gate · `escalation` gate · `publish` gate | the two retired gate names |
| **auto** · **guided** · **manual** — a goal's **mode** (`GoalMode`, `goals.default_mode`): who designs its workflow and who adopts, starts and repairs it. On a *project*, `auto` · `gated` · `manual` are its **publish policy** — a different axis, the same two words; say *auto goal* / *auto publishing* where a sentence could hold either | *guided* for the node-wide switch (that is **designing**, `design_enabled`: whether the Workflow Agent designs on this node at all); *interactive*, *autonomous*, *hands-off* for a mode |
| workflow · step · flow · run · template | lifecycle, transition, contract, criterion, plan |
| **event** — something a workflow reacts to: a time, a call, a message, a change, a signal (`StartOn`, `WaitFor`, `BoundaryOn`). A **start event** is a `start` step, one way a run may begin; a **catch** is what a `wait` holds for; a **boundary event** sits on a live step and **diverts** it — the step stops, the run takes the boundary's own flows — or **acts** beside it; a **gateway** is a step that routes (`decide` · `if` · `switch` · `judge` · `parallel`); the four **families** are events, gateways, loops and tasks ([03 — Workflows](../architecture/03-workflows.md#events)) | *trigger*, *trigger source*, *trigger scope*, *trigger action* — the words of a feature that is gone; *fire* as a noun; *probe* for a **check start**; *watch* for a project's **files** change; *interrupt* for a divert (`StepInterrupted` is what a restart does to a live step) |
| **listener** — a start event armed for a **host**: a library workflow that is **On**, or a goal that **listens** (`ListenerKey`, `ListenerHost`). **Listening** is the host's standing: what it listens with, the budget of each run, since when, **paused** and why. A workflow is **turned on** and **turned off**; a goal **listens**, **stops listening**, **listens again** | *enabled* / *disabled* for a workflow that listens; *armed* on a surface (the engine's word, and the docs'); *subscribe*, *watcher* |
| **signal** — the durable record of one occurrence, written down before anything acts on it (`Signal`); a **named signal** is one a run, an agent or a person raises (`emit`, `emit_signal`, `bisa signal emit`), its name dotted lowercase words; a signal is **held** when the content screen did not pass what came from outside, and **let through** by a person; the **chain** is the line of listeners behind it, the loop guard | *event* for the record; *topic* for a signal's name — a **topic** is a platform event's word (`run.finished`), what a `platform` start names |
| **test run** — a run begun at an event start on a sample payload, to try the start without waiting for its event; **run now** — a run by hand on a goal that listens | *dry run*, *simulate*, *fire now* |
| a run's **scope** (`RunScope`: `goal` · `workspace`) — whom it is for: a **goal's run**, or a **run in the workspace** (a *workspace run* where a noun is short of room) — a library workflow run with no goal, started by *Run…*, an event a workflow that is On listens for, or `bisa workflow run`, with its own budget, never queued (`ops::start_workspace_run`) | *standalone*, *goal-less*, *orphan* or *detached* run; *ad-hoc run* |
| **home** (`Home`: a goal, or a run in the workspace) — where a run's truth is filed: the journal, the snapshots, the work items, the ledger, the results and the scratch folder; an ask is decided through its home | *owner* or *parent* for it — a goal's **parent** is the goal it refines |
| attach / detach | link / unlink; owning goal |
| workstream | the older noun for a checkout of a project; branch-only or checkout-only words for it |
| work item | task, job |
| code host — `CodeHost`, `codehost` in paths and keys, `code_host` on the wire | the smithing word for the service that hosts a repository's pull requests |
| **ssh-agent** — OpenSSH's key agent, always hyphenated and lower-case | *agent* alone for it — that word is the platform's; *the agent holds the key* |
| profile (by organization) · organization or owner (the remote's namespace — a user, an org, a Bitbucket workspace or a GitLab group path) · account (a code host login) · key (an SSH key pair, named by its file) · **kind** (`CodeHostKind` — `github`, `gitlab`, `bitbucket`: which code host a remote is, as distinct from its *host*, the instance it lives on) | identity for a profile; user for an organization; token for an account (the token is what an account is stored as, not what it is); *provider* or *platform* for a kind |
| pull request — the platform's one word on the wire and in Rust (`PullRequest`); the desktop says the host's word (*merge request* on GitLab) through `codeHostWords.mjs` | *MR* in Rust or a route |
| the Git verbs (`gitWords.mjs`): **Discard** (a working-tree change goes back) · **Delete** (a file, a branch, a tag, a remote, a note — gone) · **Drop** (a stash entry) · **Abort** (an operation half-done) · **Continue** (finish it, every conflict settled) · **Skip** (past the commit it stopped on) · **Revert** (undo a commit with a new one) · **Switch to X** (a branch) · **Check out** (a remote branch, as a tracking branch) · **Detach at X** (a commit) · **Restore** (Safety); the places *Git › Changes*, *Git › Branches › Safety*, *About › Settings*; a file's standing in Changes — **staged · unstaged · untracked · conflict** — the chips a row wears, one per side, never a section | *throw away*, *abandon*, *remove*, *checkout* for a branch, *Go ahead* or *Continue* on a confirmation, an arrow (→) for a place, *Not staged* for the standing, a *section* for the Changes tree |
| **comment** — a reviewer's inline conversation on a pull request, with its replies, resolved on the code host; the wire and the Rust keep the host's word (`ReviewThread`, `review_threads`) | *thread* for it on any desktop surface or in the guide — a **thread** is a goal's conversation, nothing else |
| **conversation** — a saved exchange a person starts with agents: an id, an **origin**, a title, its messages, archived or not; many per origin (`Conversation`, `ConversationId`, `/conversations`, a goal's Conversation tab, a workflow's Agent pane, the drawer beside a note or a drawing and the IDE's Agent panel — one surface everywhere; [13 — Conversations](../architecture/13-conversations.md)) | *chat*, *agent session* or *thread* for it; *workstream thread* — a checkout has conversations |
| **Events** — the Settings panel for `events.*`, under *Automation*; the bolt (`ICON.signal`) is a signal's glyph wherever one is drawn. *Automation* is the Settings heading over Events · Goals · Workflows · Budgets and nothing else | a destination, a tab or an Inbox source of their own for events — what starts a workflow is drawn in the workflow, and a listener's news is its host's |
| **hold** — what a floating editor (a note's, a drawing's) registers with its panel's leave guard and the quit question: dirty, save now, let go; leaving a dirty hold **asks** — *Save*, *Don't save*, *Cancel* | *lock*, *dirty flag* for the thing itself; *Discard* as a button |
| **origin** (of a conversation) — what it is about and where its turns run: `node` · `workspace` · `goal` · `workflow` · `project` · `workstream` · `drawing` · `note` (`ConversationOrigin`); the **conversation drawer** is the resizable column beside a note or a drawing that holds its conversations | *scope* for it — a **scope** is which message stream a message is in: `channel` · `goal` · `conversation` |
| **session** — one live run of a harness, in four **kinds** (`SessionKind`): `worker` · `guided` · `conversation` · `terminal`; a conversation's session is its **turn**, a note's answer included | *persona*, *interactive session*, *chat session*; a session as a place a person sends something to — a hand-off goes to a conversation |
| **thread** — a goal's conversation, where the Workflow Agent designs and gates are asked | a workstream's or a project's *thread* — those have conversations |
| **effort** — how hard a model works on a task (`Effort`): `minimal` · `low` · `medium` · `high` · `xhigh` · `max`, and **auto** where one is asked for (`EffortChoice`) — the Decision-Making Agent names the level. A level is **fitted** to what a model takes; an agent, a model or a step that names none **inherits**. One word for every harness, whatever the harness calls its own control ([06](../architecture/06-agents-and-teams.md#effort)) | *thinking level*, *reasoning effort*, *reasoning* or *variant* on a surface or in the domain — those are harnesses' own words and stay inside their adapters; *off* or *none* as a level — thinking switched off is not an effort |
| **thinking** — the reasoning a harness streams before an agent's words (`ProgressEvent::ThinkingDelta`), kept beside the reply (`MessageBody::Post { thinking }`) and shown folded above it, shown or hidden by the timeline's toggle | *reasoning trace*, *chain of thought* on a surface; a *summary* or a *compaction* of a conversation — the harness keeps and compacts its own context, the platform summarises nothing |
| **Guard** — the Settings menu word for the Tool & Commands Guard; the feature keeps its full name in prose | *tool guard*, *command guard* alone |
| **usage** — what a harness's *account* has left: its limit windows (*5h*, *Weekly*, a model's week as its own word — *Fable*) and how much of each is used, read from the harness's own source (`UsageReport`, `GET /harnesses/{id}/usage`); **cost** is what one session spent (`SessionCost`) | *quota*, *rate limit* for the windows on any surface (a *rate limit* is the failure the classifier names); *usage* for a session's tokens |
| **load** — what the machine is doing: its CPU, GPU, memory and disk, the host's figures in the footer's read-outs; a **share** is what one thing the platform can name — the desktop app, the node, a harness session, a terminal, a goal, a project, a workflow — takes of it, its process tree attributed to the nearest of those (`shell/resourceModel.mjs`, `src-tauri/src/attribution.rs`) | *usage* for either (a harness account's is **usage**), *telemetry*, *metrics* on a surface |
| **mark** — a session's state glyph (`SessionMark`), a harness's own glyph (`harnessMark` — the harness's real mark, from a free set) and the platform's own (`PlatformMark` — the file `logo/logo.svg`, ours; the OS *icon* is that file rasterised); a **dot** is a terminal's liveness and nothing else | *dot* for a state; *icon* or *logo* for a harness mark or the platform's |
| the Inbox's words: an **ask** — a gate, a question or a held step, something owed to you, answered in the Inbox; a **notice** — something that happened to a thing you are tied to (`engine/notices.rs` names the list), read in the Inbox and opened from it, worded as the Pulse words the same fact; a **row** — the thing itself: a goal, a channel, a direct channel, a workstream, a project, a workflow | *notification* for a row or a notice (a notification is the OS's, `notificationsModel.mjs`); *event*, *feed* or *alert* for the Inbox or its rows; *needs action* in prose (the wire's `needs_action` is an ask) |
| **material** — what a theme family's surfaces are made of: *opaque* (Harbor, Orchard, Dune, Suede) or *glass* (Glass, the default family — translucent panes that frost their backdrop; `Material`, `FAMILIES[].material`, the `--material-*` roles, `theme/material.css`); **matte** — Suede's look, no gloss and no drop shadow, a card told by tone and border; a **pane** is an element the material frosts (`data-pane`); a **sheet** is a pane one reads and writes on — the notes overlay — which lays `surface` over its own `bg` ground, so it is nearly opaque where a glanced-at pane (a menu, a tooltip) stays glass | *transparent theme*, *blur theme*, *vibrancy* for glass; *flat* for matte |
| **artifact** — what an agent (or a person) made to be looked at, carried by a message and rendered live; **attachment** — a file handed over as a file; **result** — a work item's captured patch (`results/<WorkItemId>.patch`, `EntryKind::Result`); **document** — a file a person gave a goal as its context, under the goal's `documents/` (`JournalPayload::Document`, `EntryKind::Document`) | *artifact* for a captured patch or for a run's output; *attachment* for a thing that renders, or for a goal's document |
| **log** — the diagnostic log: the files under `logs/` a process writes about itself (`bisa-log`, the `logging.*` settings, Settings › Node › Logging); a goal's **journal** is its signed history (`bisa log <goal>` prints it); the **activity log** is the Pulse's truth file (`activity/`) | *log* for a journal or for the Pulse's file in prose; *telemetry* on any surface — nothing is sent anywhere |
| **queued** (`RunStatus::Queued`) — a run made behind a goal's live one: it holds its frozen workflow and inputs and starts on its own, in order, when the goal has no live run; a run in the workspace is never queued | *pending* (a step's word), *scheduled* (a schedule start's), *attempt* for it (already a synonym of run) |
| **live** run — a run that is started and unfinished, `running` or `waiting`: a goal's one, or any of a workflow's runs in the workspace, several at once | *active*, *current* for it — the **current** run is the live one, else the latest that started |
| **stop** — a person ends a goal's live run and withdraws its queued ones; the goal stays open and reads `draft`; the run's status is `cancelled`, its cause *stopped* (`ops::stop_goal`, `bisa stop`); a run in the workspace is stopped alone (`ops::stop_run`, `bisa workflow stop --run`) or with every one of its workflow's that goes (`ops::stop_workflow`) — never a goal's from the workflow | *abort* (a session's, git's), *cancel* alone (the status, a dialog's dismiss), *close* (the goal's own move) |
| **restart** — stop the live run (cause *restarted*) and start a new run of the same workflow with the same inputs at once, ahead of the queue; on a goal with no live run, run the last run's workflow and inputs again (`ops::restart_goal`, `bisa restart`); a run in the workspace restarts as a new run with its inputs, at the same start, on the same event and under the same ceiling (`ops::restart_run`, `ops::restart_workflow`) | *retry* (a step's, the design's) |
| **new run** — a run of the goal's workflow with the inputs the person gives: started now when nothing is live, queued otherwise (*New run…*, `bisa run --new`) | *start again* |
| **withdraw** a queued run — take one run out of the queue before it started: `cancelled`, cause *withdrawn* | *drop* (a stash's) |
| a cancelled run's **cause** (`CancelCause`) — why: `stopped { rationale? }` · `restarted` · `withdrawn` · `closed { reason }` · `retired` (a run in the workspace whose workflow was archived or deleted while it went) | a `ClosureReason` on a run — that is the goal's |

The boundary is identifier-aware: a longer word — *intentional* — is not the noun, and needs no
exception.

*Propose*, *proposal* and *proposed* are live vocabulary — the Workflow Agent proposes a workflow or
an amendment, and a person adopts it — and are not lint rules: the lint's word boundary cannot tell a
noun from the verb's object.

## The lint

```sh
scripts/lint-terminology                 # the whole tree
scripts/lint-terminology docs desktop    # a subset
scripts/lint-terminology-test            # the lint's own fixtures — the one file allowed to spell the banned words
```

It runs first in `just lint` because it needs no toolchain, and in CI. It reports a term, a
location, and the replacement to reach for — it is not a rename tool: choose the replacement, and
reword the sentence where the word was ordinary English.

A third-party identifier that cannot change is excused **in place**, with a reason:

```ts
CircleDot, // terminology-lint-ignore: circle - lucide-react icon identifier, third-party API
```

`.terminology-lintignore` lists paths the lint skips: `lab/*`, third-party study material that is
never shipped. Nothing else belongs there.

## Grammar that follows from the rename

The article changes with the noun: *a goal*, never *an goal*. A mechanical rename leaves that behind
and the lint does not catch it; a reviewer does.
